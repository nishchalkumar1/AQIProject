
# API Documentation

Base URL: `http://127.0.0.1:8000`

## Endpoints

### 1. Welcome
- **URL**: `/`
- **Method**: `GET`
- **Description**: Verifies that the API is running.
- **Response**:
    ```json
    {
      "message": "AQI Insight API is running"
    }
    ```

### 2. Get Available Cities
- **URL**: `/cities`
- **Method**: `GET`
- **Description**: Returns a list of Indian cities available in the database.
- **Response**:
    ```json
    {
      "cities": ["Delhi"]
    }
    ```

### 3. Get Live Data
- **URL**: `/live-data`
- **Method**: `GET`
- **Query Parameters**:
    - `city` (string): Name of the city (e.g., "Delhi").
- **Description**: Fetches the most recent live AQI and pollution data for the specified city.
- **Response**:
    ```json
    {
      "id": 500,
      "city": "Delhi",
      "datetime": "2023-01-31T23:00:00",
      "pm25": 145.5,
      "aqi": 318.0,
      "hour": 23,
      "day_of_week": "Tuesday"
    }
    ```

### 4. Get Historical Data
- **URL**: `/history`
- **Method**: `GET`
- **Query Parameters**:
    - `city` (string): Name of the city.
    - `period` (string, optional): Time range, defaults to "24h". Supports "24h", "7d".
- **Description**: Returns historical AQI data points for the dashboard charts.
- **Response**:
    ```json
    {
      "data": [
        { "datetime": "...", "aqi": 300, ... },
        ...
      ]
    }
    ```

### 5. Get Forecast
- **URL**: `/forecast`
- **Method**: `GET`
- **Query Parameters**:
    - `city` (string): Name of the city.
- **Description**: Returns the 24-hour AQI forecast generated by the ARIMA/LSTM model.
- **Response**:
    ```json
    {
      "forecast": [
        {
          "datetime": "2023-02-01T00:00:00",
          "pm25": 150.0,
          "aqi": 322,
          "horizon": "1h"
        },
        ...
       ]
    }
    ```

### 6. Get Health Advisory
- **URL**: `/health-advisory`
- **Method**: `GET`
- **Query Parameters**:
    - `aqi` (integer): Current AQI value.
- **Description**: Returns health effects and precautions based on the AQI CPCB category.
- **Response**:
    ```json
    {
      "effect": "Respiratory illness...",
      "precaution": "Avoid outdoor activities..."
    }
    ```
